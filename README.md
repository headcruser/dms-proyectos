# DMS PROYECTOS

Herramienta personal para gestionar proyectos.

## Como instalar el proyecto

Instalar dependecias de php
```
composer install
```

Correr migraciones
```
php artisan migrate --seed
```

Instalar dependencias de npm

```
npm install
```

Correr el proyecto para entorno de desarroll
```
npm run dev
```
